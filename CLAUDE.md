# Conteúdo de Fisioterapia — modo econômico de tokens

## Fluxo por etapas (cada etapa = um agente com o modelo mais barato que dá conta)
| Etapa | Agente | Modelo | Quando usar |
|---|---|---|---|
| 1. Ideias/pautas | ideias-fisio | Haiku (barato) | brainstorm, calendário, temas |
| 2. Roteiro de vídeo | roteirista-fisio | Sonnet | reels, TikTok, Shorts |
| 3. Posts/legendas | copy-fisio | Sonnet | legenda, carrossel, stories, hashtags |
| 4. Revisão final | revisor-fisio | Haiku (barato) | checagem técnica + ética COFFITO |

Agentes ficam em `.claude/agents/`. Chame pelo nome: "use o roteirista-fisio para a ideia 3".

## Regras para economizar créditos
1. Mande o briefing completo de uma vez: público, tema, formato, duração, tom, CTA.
2. Peça em lote (ex.: "10 ideias", "3 roteiros") em vez de um por mensagem.
3. Para ajustes, peça só o trecho: "reescreva apenas o gancho" — nunca o texto todo.
4. Não use agentes para coisas simples (trocar uma palavra, uma hashtag): peça direto.
5. Use `/clear` ao trocar de assunto para não carregar histórico antigo.
6. Respostas sem introdução nem explicação — só o entregável.
7. Revisão (etapa 4) só no conteúdo final, não em rascunhos.
